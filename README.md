# valt-ferramentas

Bibliotecas e ferramentas comuns do Valt: caminhos, checagem de caminhos, PDF, grafo, painéis e ambiente.

Use `python3 checar-caminhos.py`, `python3 html-para-pdf-imagem.py <html> --continuo` e `python3 gerar-grafo-valt.py --saida <html>`.
As instruções narrativas vivem em `~/Valt/Ferramentas/valt-ferramentas/README.md`.
